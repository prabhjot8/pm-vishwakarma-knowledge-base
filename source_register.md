3. **Government of India scheme information:** Use the official portal and the latest scheme guidelines/notifications linked there.

## How to cite sources in this repository
For each rule or benefit, record:
- Exact document title
- Issuing department
- Publication/revision date
- Page, section, paragraph, or table number
- Official URL
- Date accessed
- Whether the statement is a direct requirement, a summary, or an interpretation

## Verification status
This repository is a structured draft for an academic practical. The statements in the knowledge base are summaries and should be verified against the current official guidelines before public or operational use. No claim should be treated as currently verified solely because it appears in this repository.
